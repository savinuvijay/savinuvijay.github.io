PLAY THE GAME
01 / THE IDEA
×

Making programming tangible through play.

Programming is fundamentally about breaking problems into smaller steps, arranging instructions in the right sequence, and understanding how those instructions work together.

I wanted to explore a way of introducing these concepts to common people without making the experience feel like a traditional programming lesson.

That idea became TangleTrek — a puzzle adventure where players guide a character through a grid-based world by constructing sequences of visual instructions.

Instead of writing code, players experiment with actions, arrange them into sequences, and watch their instructions come to life.

The goal was simple: make the fundamentals of programming logic approachable, visual and enjoyable through play.

Audience: Beginners and puzzle enthusiasts.

Goal: Make programming logic approachable through interactive gameplay.

Challenge: Translate abstract programming concepts into intuitive game interactions.

02 / THE GAMEPLAY
×

Explore. Program. Execute.

TangleTrek revolves around a simple gameplay loop: understand the environment, construct a sequence of instructions, and execute it to guide the character towards the goal.

  1. 01 Explore

    Understand the game board, identify the goal, and plan a possible route through the grid.

  2. 02 Program

    Choose actions from the action library and arrange them in the sequence builder. Combine instructions and use repeat blocks to create more structured sequences.

  3. 03 Execute

    Run the sequence and watch the character follow the instructions through movement and animation. Observe the result and experiment with a different sequence when needed.

03 / FROM CHARACTER TO GAME
×

An experiment-driven journey.

TangleTrek didn't begin with a finished game design or a predefined interface. Almost every part of the experience started as an experiment. It then evolved through a series of such experiments, growing from a simple character into a complete playable game.

I took a bottom-up approach, starting with a single character and gradually building the systems around it.

  1. 01. THE CHARACTER

    Started with a simple character and explored its visual identity.

  2. 02. MOVEMENT & ANIMATION

    Experimented with the character's movements and animations, gradually bringing it to life.

  3. 03. THE ACTIONS

    Defined the core instructions players could use to control the character, starting with actions such as moving forward and turning.

  4. 04. ACTION LIBRARY

    Organised the available actions into a library, making them accessible to players as reusable visual instructions.

  5. 05. SEQUENCE BUILDER

    Built a workspace where players could arrange actions through drag-and-drop interactions. Repeat blocks added another layer to the instruction-building experience.

  6. 06. THE COMPLETE GAME

    Brought the individual experiments together, refined the visual presentation and developed the experience into a complete game with 10 playable levels.

Each experiment helped shape the next part of the experience. It was an iterative cycle of building, testing and refining.

04 / INTERACTION DESIGN
×

Building with visual instructions.

The interface makes programming logic tangible through a small set of clear, interactive building blocks.

Action library: Players choose visual actions to control the character.

Sequence builder: Actions are arranged in order using drag-and-drop interactions.

Repeat block: A group of actions can be repeated to build longer sequences with fewer steps.

This interaction model encourages players to form a plan, run it, observe the result, and adjust their instructions.

05 / ENGINEERING
×

Turning interactions into a playable experience.

TangleTrek brings together a reactive interface and a 2D game-rendering engine.

Svelte handles the component-based interface and player interactions.

PixiJS renders the game board, tiles, character movement, and animation.

The project brought together several areas of frontend development:

  • Component-based interface development
  • Interactive game-board rendering
  • Character movement and animation
  • Visual instruction and sequence-building interactions
  • Drag-and-drop functionality
  • Game execution and interaction feedback

I designed and developed the complete experience independently, bringing together the interface, gameplay interactions and visual presentation.

06 / MOBILE EXPERIENCE
×

Taking the game mobile.

The game needed to remain usable on smaller screens without losing the core interaction experience.

Adapting the interface meant rethinking how players interact with the action library and sequence builder in a more constrained space.

I experimented with touch interactions, drag-and-drop behaviour, layout adjustments and the overall gameplay flow to make the experience work across desktop and mobile devices.

The objective was not simply to fit the desktop interface onto a smaller screen, but to preserve the essential gameplay interactions.
